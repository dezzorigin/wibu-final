WibuFinal — how data flows

Fully static site. The browser does all the fetching; there is no backend of WibuFinal's own. Favorites never leave the device.

Read it as: Pages serves only files. The catalog, posters, and stream each come from a different third party, and each can fail independently — the app shows a clear state for each instead of a blank page. Favorites are the only data WibuFinal keeps, and they stay in localStorage on the visitor's own device.
